# 給 Claude 用的 Amazon 數據分析套件

一套規則，讓 Claude Project 變成一個嚴謹的 Amazon 數據分析師。你上傳自己的報表，Claude 幫你算出廣告到底帶來了什麼、營收為什麼變了、接下來該做什麼。

[English](README.md)

---

## 它解決什麼問題

Amazon Attribution 照理說可以告訴你，站外廣告（Google、Meta、TikTok、網紅）在 Amazon 上賣了多少。實際上它常常少算，很多賣家甚至根本用不了。

這套方法不靠它。Claude 用你手上本來就有的報表，把站外的效果重新算出來：廣告點擊、Business Reports、站內廣告報表。如果你有裝 Amazon Attribution，Claude 會用你自己的數字，量出它少算了多少。

其他 Amazon 數據也一起看：站內廣告、Buy Box、庫存、新品，還有接下來 13 週。

---

## 給專業人士：這套跟一般做法哪裡不一樣

- **營收拆成八個部分，加起來差一塊錢都不行。** 常態基線、站內廣告直接和間接、站外直接和間接、外部事件直接和間接、原因不明。沒有任何一塊錢是說不清楚的。
- **站外直接一律從點擊一路算到訂單，**不拿「剩下的錢」倒推，所以沒辦法被灌水去填缺口。
- **間接效果要有證據才算：** 看時間和份量。直接訂單變多之後，自然訂單有沒有跟著變多？多得越多，跟得是不是越多？另外要有對照組，也要排除本來就在漲的趨勢。
- **不給任何管道加權。** 每張多出來的訂單一樣重。「Google 流量對排名算 3 倍」這類說法追不到可靠來源，套件裡寫了為什麼。
- **每個數字都是程式算出來的，附最可能的數字、90% 範圍和標籤**（實測、推導、外部、假設、使用者的決定）。不准回答「算不出來」。
- **附一份「到處流傳卻查不到可靠來源」的清單，**每條都對照過論文、專利和官方文件，Claude 不會拿來填缺口。
- **沒有毛利資料，就不給砍預算或加碼的建議，**改給打平毛利率。

**用已知答案測過兩次。** 我自己編了一批報表，事先埋好 Google 的真實效果：帶來 1.68 萬美元銷售、ROAS 2.3、每次點擊大約多出 0.48 個 Sessions，而且沒有間接效果。
- **第一次：** 總數接近（1.80 萬），但拆法不對：大約三分之一被放進「間接」，站內廣告也被算了一筆埋的時候設定為「本來就會買」的銷售。我照結果改了規則。
- **第二次，同一批資料、新規則：** Google 直接 1.58 萬美元（90% 範圍 0.50 到 2.45 萬）、ROAS 2.2、每次點擊多出 0.48 個 Sessions、間接 0。都在埋的答案的 6% 以內。
- **限制：** 這是假資料，而且和套件用同一個假設：廣告帶來的訪客，轉換率跟一般訪客一樣。另外，沒有站內廣告開開關關過的時段，套件分不出站內廣告真正多帶來多少；它會照實講，並給 0 到 100% 的範圍。

檔案刻意寫得很白話。Claude 需要的技術細節，放在標著「給 Claude 的細節」的格子裡。

## 你會拿到什麼

一次完整分析分四個停點，每個停點做完 Claude 都會停下來等你。

1. **事實確認：** Claude 讀完報表，列出它看到的事（缺貨、Buy Box 被拿走、促銷），只問報表看不出來的事。
2. **執行計畫：** 要算什麼、用哪些方法、拿哪幾段期間來比。
3. **結果：** 主要數字和範圍，以及哪些檢查過了、哪些沒過。
4. **深挖和報告：** 把發現拆到「誰該做什麼」，好消息壞消息都講，最後出一份報告。

每個停點 Claude 都會告訴你：做了什麼、替你決定了什麼、自己改掉了哪些錯。分析結束時會給你一份可以下載的分析過程說明，每個數字都查得到怎麼來的、重算得出來。

## 怎麼開始

1. 建一個 Claude Project。
2. 上傳**一個**語言資料夾（`en/` 或 `zh-TW/`）裡的 `01` 到 `09`，加上 `glossary.md`。
3. 把 `00-project-instructions.md` 裡的指令那段，貼到 Project 的指示欄。

然後上傳你的報表，打：
`開始分析：美國，9/1–9/30，Google 廣告除了 Amazon Attribution 看到的，到底多帶了多少銷售？`

不知道要拉哪些報表？看 `09-report-checklist.md`。

## 開始之前先知道

- **只處理 Amazon。** 自己的官網、Walmart、實體通路都不在範圍內。
- **程式執行一定要開。** 每個數字都是 Claude 用程式算的。
- **很吃用量。** 試跑時光第 1 停就跑了好幾分鐘。一次只分析一個市場、一個問題。
- **報表要自己拉。** 套件會告訴你要哪些。它不會跟你要密碼，也不會幫你登入。
- **為什麼用 Claude：** 我自己實際用下來，這種嚴謹、步驟多的分析，Claude 做得比其他 AI 好。規則都是純文字，你可以拿到別的工具試，但它是在 Claude 上寫、在 Claude 上測的。
- **這些是估計，不是保證。** 每個數字都附範圍和信心標籤，決定由你自己做。

本套件與 Amazon、Anthropic 沒有任何關係。
